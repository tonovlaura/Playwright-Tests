# Playwright Test Automation

A QA test automation project created to practise end-to-end testing with Playwright and TypeScript.

## Project overview

This project demonstrates automated testing of web application functionality using Playwright. The tests cover different user scenarios and verify that the application behaves as expected.

## Project Background

This project was initially created by following the [Playwright Test Automation Tutorial](https://youtu.be/788GvvcfwTY) to learn the fundamentals of Playwright and understand how an automated test project is structured.

After following the tutorial, I expanded the project with my own additions and modifications. The additional work is documented directly in the relevant test files.

## What I practised

- End-to-end test automation with Playwright
- Writing and structuring automated test cases
- Positive and negative test scenarios
- Assertions and test validation
- Test organisation and configuration
- TypeScript
- Running and reviewing automated test results

## Technologies

- Playwright
- TypeScript
- Node.js
- Git / GitHub

## Running the tests

Install dependencies:

```bash
npm install
```

Run the tests:

```bash
npx playwright test
```

View the test report:

```bash
npx playwright show-report
```
